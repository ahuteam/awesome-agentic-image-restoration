# Contributing

Please propose changes through a pull request. For a new paper, include the exact title, source version/date, DOI or primary-paper URL, task, deployed observation/action/feedback interfaces, memory lifetime, coordinating roles and a short inclusion rationale. Distinguish preprints from publications and link code only when it is author-associated.

Keep one study identity for preprint/published versions. Do not duplicate rows to represent overlapping P labels. Mark unknown fields explicitly; do not infer a clinical endpoint, run variance, sample count or available implementation from a title.

For a numerical correction, provide the source table/page, setting, metric direction, sample unit and comparator. Different tool banks, input generation or memory state require separate protocol units. Report why values are comparable rather than sorting a cross-paper leaderboard.

Run `python3 scripts/validate_evidence.py`. Keep private reviewer reports, editorial correspondence, author contact lists and unpublished response letters out of public contributions. Do not commit third-party PDFs or credentials.
